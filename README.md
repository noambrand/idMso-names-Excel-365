# idMso-names-Excel-365
Excel 365  idMso PNG  and names
Exports every idMso AS 32 × 32 PNGs
3852 images is only what Excel exposes on your machine.

The christianjunk ImageMso catalog lists 8,899 distinct idMso icons across all Office apps (Word, PowerPoint, Outlook, etc.).
Excel loads a subset of that master list; Office 2016/365 galleries show thousands more icons used by the other hosts.
